# Code of Conduct

## Our standard

EventMonitorAI is intended to be a respectful, constructive and technically focused community. Contributors are expected to communicate professionally, accept differing experience levels and give feedback on ideas and code rather than people.

Unacceptable behavior includes harassment, threats, discriminatory language, publication of private information, deliberate disruption and sharing recordings or credentials without authorization.

## Scope

This code of conduct applies to the repository, discussions, issue trackers, pull requests and project-related communication.

## Enforcement

Security issues and conduct concerns should be reported privately as described in [SECURITY.md](SECURITY.md). Maintainers may edit or remove content, close discussions or restrict participation when necessary.

This document is based on the principles of the Contributor Covenant and is intentionally concise for the current project stage.
